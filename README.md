# Khmer Learning

Mobile-first Khmer learning site for Ken.

## Publish with GitHub Pages
1. Upload `index.html` and `README.md` to the root of the `Khmer-learning` repository.
2. Commit the files to the default branch.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the default branch and `/ (root)`, then Save.
