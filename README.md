# Khmer Learning

Ken 的每日柬語課程庫與歌曲學習頁。純 HTML、CSS、JavaScript，無建置步驟。

網站入口：https://politicschao-commits.github.io/Khmer-learning/

網站可直接開啟，不需要帳號登入。歌詞的個人編輯僅保存在目前瀏覽器，不會跨裝置同步。

## 歌曲學習頁
- 表頭為歌名、YouTube 圖示和原唱連結，在新分頁開啟；不載入內嵌播放器。
- 桌面以 2:1 排列歌詞與詞典；手機版依序顯示。
- 使用者提供的歌詞共 26 段，含重複段落、間奏和致謝，逐段搭配近似拼音與繁體中文意譯。
- 右側有 36 個本曲詞彙，包含柬文、拼音、中文與語境說明。
- 點選一句會篩選其相關詞彙；支援柬文、拼音、中文搜尋及「顯示全部」。這是本曲詞彙表，並非完整通用字典。
- 支援隱藏拼音／中文、手動標記句子；沒有播放時間同步。
- 可更換 YouTube 連結。不同影片使用各自的歌詞資料，不會挪用上一首歌的詞彙。
- 編輯格式為每段三行：柬文、拼音、中文；段落間空一行。編輯依影片 ID 儲存在目前瀏覽器 localStorage，未同步至其他裝置。已有本機編輯時優先顯示本機內容。
- 拼音、翻譯及詞義為學習初稿，尚未經母語教師校閱。

## 每日四句
保留原 Day 1 四句、拼音、中文及詞彙；新增 Day 2 聽歌情境練習句（非歌曲原詞）。有課程目錄、上一課／下一課、`#day-1` / `#day-2` 連結、中文隱藏，以及課程／句子／不重複詞彙統計。

## 檔案
- `index.html`：頁面結構。
- `styles.css`：響應式外觀；Google Fonts 不可用時使用系統字型。
- `lessons.js`：每日課程資料。
- `app.js`：每日課程切換、顯示及統計。
- `song.js`：歌曲標題、歌詞與本曲詞彙。
- `sing.js`：歌曲連結、歌詞編輯、顯示控制及詞典搜尋。

## 新增資料
在 `window.KHMER_LESSONS` 最後加入課程，保持既有 ID 穩定。每課包含 `id`、`day`、`title`、`song`、`description`、`search`、`sentences`；每句包含 `kh`、`roman`、`zh`、`vocab`，每個詞彙包含 `kh`、`roman`、`zh`。

歌曲以 YouTube 影片 ID 為 `window.KHMER_SONGS` 的鍵，包含 `title`、`lines`（每項依序柬文、拼音、中文）及 `words`（每項依序柬文、拼音、中文、語境說明）。

## 預覽與發布
可直接開啟 `index.html`，或以靜態 HTTP 伺服器預覽。GitHub Pages 發布須包含以上全部七個檔案；合併至部署分支根目錄後使用既有 Pages 流程。
